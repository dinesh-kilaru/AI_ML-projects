## Customer Churn Prediction



This project is to train an ML model with various training algorithms and let the model spot the customers who are about to leave and act fast.


#### Tools used:



* Pandas: To load the dataset
* Seaborn, matplotlib.pylib: used for visualising the data
* sklearn.linear\_model, sklearn.tree, sklearn.ensemble, sklearn.neighbours: To train the model
* sklearn.preprocessing: To encode and scale the data
* sklearn.metrics: To measure the score of predictions



#### Tasks:

1. Data preprocesed
2. Performed EDA
3. Encoded categorical features to numerical features
4. Scaled to numerical values
5. Detected and treated Outliers
6. Analysed correlation
7. Trained the model using 4 training algorithms
8. Measured the accuracy score
9. Chosen the best model
10. saved the file using joblb
